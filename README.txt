MY MONEY V5
==========
This build focuses on the professional responsive UI plus the working local money engine.

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server.
4. Test:
   - Create an account and opening balance.
   - Add income / expense.
   - Transfer from one account to another.
   - Create a goal and fund it from an account.
   - Create budgets/categories/account types.
   - Check Dashboard Safe to Spend and Smart Money Decision.
   - Export/import backup.

Google/Firebase sync is intentionally left as the next connection step so the local calculations can be verified first.
